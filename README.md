## Основные выполненные операции

- `git init` — инициализация локального репозитория с основной веткой `main`;
- `git status` — контроль рабочего дерева на каждом шаге;
- `git add` — поэтапное добавление исходников, документации и служебных файлов;
- `git commit` — осмысленные коммиты (исходный код, документация, подготовка к публикации, отчёт и доказательства);
- настройка remote: `git remote add origin <URL>`;
- `git push -u origin main` — публикация ветки и установка upstream;
- проверка истории: `git log --oneline --decorate --graph --all`.

Полные реальные результаты команд сохранены в `evidence/git_validation.txt`.

## Запуск / просмотр проекта

Проект — это набор SQL-скриптов PostgreSQL и скриптов на Python/Bash, поэтому
«запуск» означает воспроизведение базы данных предыдущей лабораторной работы.

Требования:

- Docker (образ `postgres:17` подтягивается автоматически) — либо локальный PostgreSQL;
- Python 3 с `python-docx` и `Pillow` — только для повторной сборки отчёта Word.

Проверка содержимого и истории репозитория:

```bash
git log --oneline --decorate --graph --all
git status
git remote -v
```

Воспроизведение базы данных из ЛР №2 (из корня репозитория):

```bash
cd lab-02-data-warehousing
# поднять изолированный PostgreSQL 17 в Docker на порту 55432
docker run -d --name video_rental_lab_pg -e POSTGRES_PASSWORD=labpass \
  -e POSTGRES_USER=labuser -p 55432:5432 postgres:17

# создать чистую учебную базу
docker exec video_rental_lab_pg psql -U labuser -d postgres \
  -c "DROP DATABASE IF EXISTS video_rental_lab;" \
  -c "CREATE DATABASE video_rental_lab;"

# полный прогон: схемы 3NF и Data Vault, данные, проверки
./run_all.sh
```

Подробное описание модели, структуры каталогов и команд — в
`lab-02-data-warehousing/README.md`.
